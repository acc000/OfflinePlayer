# Offline Player (Material You)
Reproductor offline para Android 16 (API 36): carpetas del movil, shuffle, repeat, listas y recomendaciones con IA.

## Obtener el APK (GitHub)
1. Crea un repositorio nuevo en github.com y sube TODO el contenido de esta carpeta (incluida `.github`).
2. Pestana **Actions** > "Build APK" > se ejecuta solo (o "Run workflow").
3. Al terminar (~5 min), entra en la ejecucion y descarga el artefacto **OfflinePlayer-APK**.
4. Descomprime e instala `app-debug.apk` (permite "instalar apps desconocidas").

## Alternativa: Android Studio
Abre la carpeta, espera la sincronizacion y pulsa Build > Build APK(s).

## Primer uso
Biblioteca > Anadir carpeta > elige tu carpeta de musica. Para las recomendaciones: Ajustes > pega tu clave de API de Anthropic.
